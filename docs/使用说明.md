# 轻量网盘使用说明

系统提供登录、共享目录浏览、单文件下载、账号管理、登录记录和下载记录。全部页面由同一个服务提供，不需要构建前端，也不依赖外部 CDN。

## 本地启动

在项目目录中使用 Node.js 24.21.0：

~~~sh
nvm install
nvm use
npm ci
npm run setup
npm run init-db
npm start
~~~

访问 http://127.0.0.1:3000 。`npm run setup` 创建随机会话密钥和本地 `.env`；已有配置保持不变。首次启动也会自动建表并初始化空账号表，因此 `init-db` 可以用于提前初始化或检查，重复运行不会覆盖账号。

当前开发机另备有项目内 Node.js 24，可使用以下命令运行，Shell 的默认 Node 版本保持不变：

~~~sh
.runtime/node-v24.21.0-darwin-arm64/bin/node src/server.js
~~~

`.runtime` 仅供当前 Mac 使用；Linux 部署请使用 Linux 的 Node.js 和依赖。

## 内置账号

| 用户名 | 初始密码 | 角色 |
|---|---|---|
| admin | adminyj@2026 | 管理员 |
| user | yj@2026 | 普通用户 |

两个账号仅在账号表完全为空时创建。重启、重复初始化和程序升级都不会恢复默认密码，也不会恢复账号的启用状态。数据库中保存随机盐和 scrypt 哈希，不保存密码明文。

普通用户可以登录、退出、浏览共享文件夹和下载文件，不能修改本人或其他账号的密码。管理员进入“用户管理”，可以创建账号、启用或禁用账号、修改任意账号的密码，包括管理员本人。

修改密码后，该账号所有旧会话都会失效；管理员修改本人密码后会返回登录页。禁用账号也会撤销旧会话。系统不允许禁用最后一个可用管理员。新建账号的密码由管理员填写，长度为 6–128 个字符。

## 配置文件目录

在 `.env` 中修改 `FILE_ROOT`：

~~~dotenv
FILE_ROOT=/srv/wangpan/files
~~~

相对路径以项目目录为基准，默认值是 `./storage`。修改配置后重启服务。共享目录必须已存在且服务进程有读取与目录遍历权限；程序不会自行创建错误配置的共享路径。

所有账号共享同一目录。管理员在操作系统中放入文件，用户刷新列表即可看见。网页支持逐层浏览、面包屑返回、按名称搜索当前目录及所有子目录和每页 30 条分页。文件夹优先，名称按中文及数字顺序排列。未搜索时统计当前目录；搜索时统计当前目录及子目录的全部匹配结果，再统一分页。搜索结果显示相对路径，便于区分同名文件。递归搜索不展开目录符号链接；遇到无法读取的子目录会跳过并显示提示。

开发占位文件 `.gitkeep` 和 macOS 元数据 `.DS_Store` 不展示。指向根目录外的符号链接不展示且无法下载；内部链接正常访问。只处理普通文件和目录，不读取设备、套接字或管道。

数据库、数据库目录和项目配置不能放入可下载目录；共享目录也不能覆盖整个项目目录。物理文件只通过受登录保护的下载接口提供。

## 删除文件和目录

仅管理员在文件列表中可以看到“删除”。点击后确认目标路径，确认删除即永久移除文件；删除文件夹会连同内部文件和子文件夹一起删除。普通用户直接请求删除接口也会被拒绝。删除成功后返回原目录并保留搜索条件。

共享根目录不能删除；通过目录符号链接进入的内容不能删除，请进入实际目录操作。删除链接项或包含链接的文件夹时，不会删除链接指向的目标。服务进程需要对相关目录有写入和遍历权限，Docker 共享目录需可写挂载，见 [搜索与删除更新说明](搜索与删除更新说明.md)。

## 登录和下载记录

管理员可分别查看“登录记录”和“下载记录”，按完整用户名、完整 IP、操作结果和日期范围筛选。日期按北京时间解释，结束日期包含当天整日；记录按时间倒序显示。

登录成功、密码错误、账号不存在、账号禁用和登录受限均会留下记录。IP 与账号组合在 15 分钟内失败达到 10 次，或同一 IP 失败达到 100 次，将暂时拒绝登录并记录受限结果。会话默认从登录起固定有效 8 小时，访问页面不延长这一上限。

下载记录包含账号、文件相对路径、文件大小、IP、User-Agent、开始和结束时间，以及：

| 状态 | 含义 |
|---|---|
| 传输中 | 已写入开始记录，正在检查或发送文件 |
| 服务端发送完成 | 服务端已发送本次完整文件响应 |
| 失败 | 文件不存在、无读取权限或传输发生错误 |
| 中断 | 连接提前关闭，或服务重启时发现尚未结束的传输 |

“服务端发送完成”描述服务端传输结果，不表示浏览器已把文件保存到磁盘。每次下载请求分别记账；刷新文件列表不产生下载记录。审计开始记录保存失败时，下载接口返回 503，不发送文件内容。未登录请求返回 401，不生成归属账号的下载记录。

下载使用流式发送，支持中文和特殊字符文件名。第一版不支持 Range 断点续传，收到 Range 请求时返回完整文件；HEAD 请求返回 405，且不记为下载。

审计日志长期保留，不记录密码、Cookie 或会话凭据。需要设置保留期限时另行增加管理策略。

## 开发检查

~~~sh
npm run check
npm test
~~~

`check` 执行 JavaScript 语法检查和 EJS 模板编译检查；`test` 使用临时目录、真实 SQLite 和本机临时 HTTP 端口进行集成测试，结束后清理临时数据。两个命令均不执行前端构建。

## 目录结构

| 目录 | 用途 |
|---|---|
| src | 服务、权限、数据库、文件读取和审计逻辑 |
| views / public | EJS 页面、本地样式、图标和少量交互 |
| scripts | 配置生成、数据库初始化、源码检查 |
| test | 隔离的 HTTP 集成测试 |
| deploy | systemd 和 Nginx 配置示例 |
| docs | 使用、部署和验证说明 |
| data / storage | 默认 SQLite 目录、默认共享目录 |

本版不提供上传、重命名、公开分享、文件预览、文件夹打包或多实例部署。
