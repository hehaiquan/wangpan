# 搜索与删除更新说明

## 更新文件

替换 `src/files.js`、`src/app.js`、`views/files.ejs`、`public/app.js`、`public/style.css`。没有依赖或数据库结构变更，无需构建前端。共享目录可写时，替换后重启服务即可；浏览器强制刷新以加载新脚本和样式。

搜索现在包含当前目录及子目录，按文件或目录名称匹配，结果显示路径。管理员可在列表中删除文件或整个文件夹，普通用户无删除权限。

## Docker 配置

共享目录的挂载必须允许写入：

- Compose：将共享目录挂载末尾 `:ro` 改为 `:rw`，本项目 `compose.yaml` 已修改。
- `docker run`：删除共享目录这一项的 `readonly`，例如 `--mount type=bind,source=/home/wangpan/files,target=/srv/wangpan/files`。
- `/app` 程序目录仍可保持 `readonly`，容器的 `--read-only` 也可保留。

容器进程 UID 1000 需要对共享目录和要删除内容所在的各级目录有写入、遍历权限；删除非空文件夹还需要读取其内容。权限应按实际共享目录的属主、组或 ACL 配置。

挂载选项变更必须重新创建容器，仅重启不会生效。Compose 使用 `docker compose up -d --no-build --force-recreate`；使用 `docker run` 的现场按原端口、环境文件、数据库卷和程序挂载重新创建，只调整共享目录的挂载项。源码在镜像内的部署还需先更新镜像，源码映射部署直接替换上述文件。

删除确认会永久删除目标，文件夹内的全部内容也会被删除。共享根目录不允许删除。只读挂载或目录权限不足时页面会提示原因；目录删除失败可能已有部分内容被移除，刷新列表查看实际状态。

## systemd 配置

使用 `deploy/wangpan.service` 时，将共享目录从 `ReadOnlyPaths` 移到 `ReadWritePaths`（与数据库目录并列），本项目模板已修改。同步服务文件后执行 `systemctl daemon-reload` 和 `systemctl restart wangpan`。
