# 单目录挂载部署

使用 `wangpan-app-full-amd64-1.0.0.tar.gz`，里面已包含程序、package.json 和 Linux AMD64/musl 依赖。继续使用现有 `wangpan:1.0.0-amd64-musl` 镜像，不需要重新构建。此前的 32 KiB 纯源码包不包含依赖，不能单独用于整个 `/app` 挂载。

## 首次切换

上传完整文件包后执行：

```sh
mkdir -p /home/wangpan
tar -xzf wangpan-app-full-amd64-1.0.0.tar.gz -C /home/wangpan

docker stop wangpan
docker rm wangpan

docker run -d --name wangpan --restart unless-stopped \
  --env-file /home/wangpan/.env.docker \
  -p 8188:3000 \
  --mount type=bind,source=/home/wangpan/app,target=/app,readonly \
  --mount type=volume,source=wangpan-data,target=/var/lib/wangpan \
  --mount type=bind,source=/home/wangpan/files,target=/srv/wangpan/files,readonly \
  --read-only --tmpfs /tmp --stop-timeout 30 \
  wangpan:1.0.0-amd64-musl

docker logs --tail=100 wangpan
```

程序只需一条目录挂载。配置文件、数据库卷和共享文件仍沿用原位置。

## 以后更新

停止容器，替换 `/home/wangpan/app` 中对应的程序文件，再启动：

```sh
docker stop wangpan
# 在这里上传、替换程序文件。
docker start wangpan
docker logs --tail=100 wangpan
```

只改现有源码、页面和样式时，保留 `node_modules`、`package.json` 和 `package-lock.json`。拿到完整更新包时可整体替换 `app`，确保新包也包含配套 Linux 依赖。替换后的目录和文件应允许 UID 1000 读取、遍历。

修改 `.env.docker` 仍需重新创建容器；修改 Node.js 版本仍需更新镜像。增加或升级 npm 依赖时，更新包需携带匹配 AMD64/musl 和当前 Node.js 版本的 Linux 依赖。

本地已验证：整个 `/app` 单目录挂载、依赖加载、文件更新后重启生效、只读挂载和数据库保留。尚未在目标服务器执行此次挂载切换。
