# wangpan · 轻量共享网盘

基于 Node.js、Express、EJS 和 SQLite 的轻量共享网盘，提供账号登录、共享目录浏览、单文件下载、用户管理和操作记录查询。所有账号访问同一个共享目录，文件由管理员通过操作系统维护。

页面由服务端渲染，样式、图标及脚本均保存在项目内，无需构建前端，也不依赖外部 CDN。

## 功能

- 文件浏览：逐层访问目录、面包屑导航、当前目录文件名筛选、每页 30 条分页。
- 文件下载：登录后流式下载单个文件，支持中文和特殊字符文件名。
- 用户管理：管理员创建账号、启用或禁用账号、修改密码；普通用户仅浏览和下载文件。
- 操作记录：管理员查询登录和下载记录，按用户名、IP、结果和日期范围筛选。
- 会话管理：SQLite 持久化会话，修改密码或禁用账号后撤销旧会话。

当前不提供上传、删除、重命名、公开分享、文件预览、文件夹打包或断点续传。服务按单实例运行。

## 运行环境

- Node.js 24，项目 [`.nvmrc`](.nvmrc) 指定版本为 `24.21.0`。
- npm，用于按 `package-lock.json` 安装依赖。
- SQLite 通过 `better-sqlite3` 使用，无需单独部署数据库服务。

`better-sqlite3` 是原生模块，依赖需要在目标操作系统和架构下安装。

## 快速启动

在项目根目录执行；已安装 Node.js 24 时可跳过前两条 nvm 命令：

```sh
nvm install
nvm use
npm ci
npm run setup
npm start
```

启动后访问 [http://127.0.0.1:3000](http://127.0.0.1:3000)。

`npm run setup` 创建默认共享目录 `storage/`，并根据 `.env.example` 生成带随机会话密钥的 `.env`；已有 `.env` 保持不变。首次启动自动创建数据库和表，并在账号表为空时初始化内置账号。也可执行 `npm run init-db` 提前初始化。

将文件放入 `storage/`，登录后刷新文件列表即可查看和下载。默认仅监听本机地址；需要其他设备访问时，在 `.env` 中调整 `HOST`，部署方式见 [Linux 部署说明](docs/部署说明.md)。

## 初始账号

| 用户名 | 初始密码 | 角色 |
| --- | --- | --- |
| `admin` | `adminyj@2026` | 管理员 |
| `user` | `yj@2026` | 普通用户 |

内置账号仅在账号表完全为空时创建，重复初始化和重启不会覆盖已有账号、密码或启用状态。管理员在“用户管理”中修改本人及其他账号的密码，普通用户没有修改密码权限。

## 配置

配置示例见 [`.env.example`](.env.example)。程序读取项目根目录的 `.env`，进程环境变量优先；修改配置后重启服务。

| 配置项 | setup 生成的本地配置 | 说明 |
| --- | --- | --- |
| `FILE_ROOT` | `./storage` | 共享文件根目录，必须已存在且服务进程可读取和遍历 |
| `SQLITE_PATH` | `./data/wangpan.sqlite` | 账号、会话及操作记录的数据库文件路径 |
| `HOST` | `127.0.0.1` | 服务监听地址 |
| `PORT` | `3000` | 服务监听端口 |
| `SESSION_SECRET` | 自动生成随机密钥 | 至少 32 个字符；更换后已有浏览器 Cookie 失效 |
| `SESSION_HOURS` | `8` | 从登录起计算的固定会话有效时长，单位为小时 |
| `TRUST_PROXY` | `false` | 可信代理配置；同机 Nginx 可设为 `loopback`，也支持明确的 IP/CIDR 列表 |
| `COOKIE_SECURE` | `false` | 是否仅通过 HTTPS 发送会话 Cookie；生产 HTTPS 设置为 `true` |
| `NODE_ENV` | `development` | 运行环境，生产部署设置为 `production` |

相对路径均以项目根目录为基准。共享目录不能包含项目、配置或数据库目录；下载接口会检查登录状态和文件访问边界。

## 常用命令

| 命令 | 用途 |
| --- | --- |
| `npm start` | 启动服务 |
| `npm run dev` | 监听源码变更并自动重启服务 |
| `npm run setup` | 生成本地配置和默认共享目录 |
| `npm run init-db` | 创建数据库、表及空账号表的内置账号 |
| `npm run check` | 检查 JavaScript 语法和 EJS 模板编译 |
| `npm test` | 使用临时目录、真实 SQLite 和本机 HTTP 端口运行集成测试 |

## 目录结构

```text
src/          服务入口、配置、权限、数据库、文件读取和操作记录逻辑
views/        EJS 页面及公共模板
public/       本地样式、脚本和图标
scripts/      配置生成、数据库初始化和源码检查脚本
test/         HTTP 集成测试
deploy/       systemd 和 Nginx 配置示例
docs/         使用、部署和验收文档
storage/      默认共享文件目录
data/         默认 SQLite 数据目录，运行时生成
```
